    Before you send

    1. Check the key figures against last month's summary.
    2. Read the highlights and edit the wording in Word if needed.
    3. Send from your own email. A person reviews every summary before it reaches the sponsor.
    How this tool handles data
    • Files are read inside your browser and are gone when you close or reload the page.
    • The inventory report's date of birth column is removed as the file opens. No output ever contains it.
    • Sponsor versions contain totals only. Participant and sample lists are available to internal readers only.
    • "Save as my default" keeps your content choices in this browser only. It never stores data.
